# Roca Tile 2026 — Product Images

Product image library for the Roca Tile Book 2026 catalog, organized for use by an e-commerce site.

## Folders
- `lifestyle/` — installation/room photos for each product (kitchens, bathrooms, offices)
- `swatches/` — color/finish swatches (white background removed where possible)

## Naming
- `lifestyle/<product-slug>__lifestyle__<n>.jpg`
- `swatches/<product-slug>__<variant-slug>__<n>.png`

Use the GitHub raw URL format to embed images:
`https://raw.githubusercontent.com/arzL2o/roca-tile-2026-images/main/<path>`
